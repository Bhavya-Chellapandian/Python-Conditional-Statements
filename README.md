# 🐍 Python Conditional Statements — if, else, elif

## 📌 Overview

This repository contains Python programs demonstrating **conditional statements** using `if`, `else`, and `elif`.

The notebook focuses on applying decision-making logic to practical programming problems such as number classification, marks evaluation, character identification, discounts, ticket fares, and temperature classification.

## 🎯 Objectives

* Understand the working of `if`, `else`, and `elif`
* Apply conditional logic to solve programming problems
* Work with comparison and logical operators
* Practice nested conditional statements
* Handle different input conditions and outputs

## 📚 Topics Covered

### 1. Positive or Negative Number

Checks whether a given number is positive or negative.

### 2. Even or Odd Number

Determines whether a number is even or odd using the modulus operator `%`.

### 3. Positive, Negative, or Zero

Classifies a number into three categories using `if`, `elif`, and `else`.

### 4. Largest of Three Numbers

Compares three numbers using conditional and logical operators to determine the largest value.

### 5. Pass or Fail

Checks whether marks meet the passing requirement of **35 or above**.

### 6. Vowel, Consonant, or Special Character

Identifies whether an entered character is a vowel, consonant, or special character.

### 7. Discount Calculation

Calculates the billing amount based on purchase amount:

| Purchase Amount | Discount |
| --------------- | -------: |
| ≥ 1000          |      20% |
| 500–999         |      10% |
| < 500           |       5% |

### 8. Ticket Fare Based on Age

Determines ticket fare based on age:

| Age Group             | Ticket Fare |
| --------------------- | ----------: |
| Child (< 12)          |         300 |
| Adult (12–59)         |         600 |
| Senior Citizen (≥ 60) |         450 |

### 9. Uppercase or Lowercase

Checks whether the entered text is lowercase, uppercase, or mixed case.

### 10. Temperature Classification

Classifies temperature into:

| Temperature | Classification |
| ----------- | -------------- |
| < 10°C      | Cold           |
| 10–25°C     | Mild           |
| > 25°C      | Hot            |
